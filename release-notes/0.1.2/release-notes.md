# OpenType 0.1.2 (3)

本次更新新增「程序员词典」：内置十个可切换的术语包，并支持自定义词条，让听写、翻译和「帮我说」更准确地识别技术名词。

> **系统要求：macOS 26.0+ · Apple 芯片（arm64）**

## 新增与改进

- **程序员词典**：设置中新增「词典」标签页，内置十个可单独开关的术语包——编程通用、Git、Swift、Python、JS/TS、Shell、SQL、HTML/CSS、AI 概念、AI 厂商，同时支持添加自定义词条。
- **LLM 提示词增强**：语音中提到的词条会加入 LLM 提示词，用于听写、翻译和「帮我说」，减少技术名词被误识别或误改写。
- **自动替换**：标记为「自动替换」的词条会在送入 LLM 之前直接修正识别文本，因此原文（Raw）模式同样受益。
- README 更新为五种语言（English、简体中文、繁體中文、日本語、한국어），并配有各语言的首页插图；新增项目官网（五语言）。

## 系统要求

- **macOS 26.0 及以上**。
- **仅支持 Apple 芯片（arm64）**，不支持 Intel Mac。
- 需要在系统设置的「隐私与安全性」中授予 **麦克风**、**辅助功能**、**输入监控** 权限。
- 需要自备阿里云百炼或 DeepSeek 的 API Key（ASR），以及你所选 LLM 服务的 API Key。

## 安装与升级

下载 `OpenType-0.1.2-arm64.dmg`（或 `OpenType-0.1.2-arm64.zip`），将 `OpenType.app` 拖入「应用程序」文件夹覆盖旧版本。

本版本使用自签名证书签名，未经 Apple 公证，首次打开会被 Gatekeeper 拦截。请任选一种方式放行：

- 在「系统设置 → 隐私与安全性」中点击「仍要打开」；
- 或在终端执行：

```bash
xattr -dr com.apple.quarantine /Applications/OpenType.app
```

> 升级只要仍使用同一张证书签名，辅助功能 / 输入监控授权会保留。
