# OpenType 0.1.1 (2)

本次更新带来多语言界面、应用内语言切换、悬浮窗材质选项，并调整了 API Key 的存放方式，避免每次升级都弹出钥匙串密码提示。

> **系统要求：macOS 26.0+ · Apple 芯片（arm64）**

## 新增与改进

- **多语言界面**：界面现已本地化为简体中文、繁体中文、英文、日文、韩文。
- **应用内语言切换**：「设置 → 通用」新增界面语言选项（跟随系统 / 简体中文 / 繁體中文 / English / 日本語 / 한국어），重启后生效；系统语言没有对应翻译时回退为英文。
- **悬浮窗材质可选**：每种模式可单独选择「磨砂玻璃」或「Liquid Glass」。完整悬浮窗默认 Liquid Glass，极简胶囊默认磨砂玻璃。
- 清理了设置页文字与 README 中已移除的菜单栏「开始」项的过时说明。

## 变更：API Key 存放方式

- 由于钥匙串的访问控制与应用签名绑定，每次升级都会重新要求输入登录密码。现在 API Key 改为保存在 `~/.opentype/credentials.json`（目录权限 0700，文件权限 0600），**不再使用 macOS 钥匙串**。
- 旧版本留在钥匙串中的密钥会在首次启动时自动迁移一次。
- 注意：密钥以明文 JSON 形式保存在本机该文件中（仅当前用户可读写），请勿将该文件同步或分享给他人。这取代了 0.1.0 说明中的「API Key 只存 macOS Keychain」。

## 系统要求

- **macOS 26.0 及以上**。
- **仅支持 Apple 芯片（arm64）**，不支持 Intel Mac。
- 需要在系统设置的「隐私与安全性」中授予 **麦克风**、**辅助功能**、**输入监控** 权限。
- 需要自备阿里云百炼或 DeepSeek 的 API Key（ASR），以及你所选 LLM 服务的 API Key。

## 安装与升级

下载 `OpenType-0.1.1-arm64.dmg`（或 `OpenType-0.1.1-arm64.zip`），将 `OpenType.app` 拖入「应用程序」文件夹覆盖旧版本。

本版本使用自签名证书签名，未经 Apple 公证，首次打开会被 Gatekeeper 拦截。请任选一种方式放行：

- 在「系统设置 → 隐私与安全性」中点击「仍要打开」；
- 或在终端执行：

```bash
xattr -dr com.apple.quarantine /Applications/OpenType.app
```

> 升级只要仍使用同一张证书签名，辅助功能 / 输入监控授权会保留。
