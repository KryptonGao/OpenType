# OpenType 0.1.0 (1)

首个公开版本。OpenType 是一款面向 macOS 的全局 AI 语音输入工具：在任意输入框里说话，文字直接落在光标处。

## 三种用法

- **听写**：短按快捷键开始说话，再短按一次结束。自动去口头禅、补标点，插入到原来的输入位置。
- **语音翻译**：说完先整理再翻译成目标语言，支持 15 种语言；悬浮窗里可临时切换语言，葡萄牙语（巴西 / 葡萄牙）与繁体中文（台湾 / 港澳）可选地区用语。
- **帮我说**：按住听写快捷键不放（约 0.45 秒后进入），松开结束。模型会弄清你想表达的意思，把它细化、补全、理顺后再插入，不会编造你没说过的人名、数字或日期。
  - 可开启 DeepSeek **联网搜索**，让成品融入查到的资料，并支持调节搜索积极程度（0–100%），悬浮窗实时显示搜索进度。
  - **翻译帮我说**：按住翻译快捷键不放，成品直接用翻译目标语言写出。

## 语音识别（ASR）

- 阿里云百炼 `qwen3-asr-flash-realtime`：实时流式识别。
- 阿里云百炼 `qwen-audio-3.1-asr-flash-message`：实时流式，带实时中间结果与可选的识别端润色。
- DeepSeek：录完后整段上传识别。
- 默认识别语言覆盖百炼支持的全部 27 种语言（DeepSeek 仅支持自动检测）。

## 文字处理（LLM）

- 内置 OpenAI Responses、OpenAI Chat Completions、Anthropic Messages 三种协议适配器，兼容第三方 OpenAI 兼容服务。
- 支持多个 Profile，每个 Profile 可单独设置推理强度（自由文本）。
- 三档处理等级：原始 / 标准 / 深度整理。

## 使用体验

- **快捷键完全自定义**：单个按键、组合键、单个修饰键（区分左右）或 `fn` 均可。
- **不抢焦点的悬浮窗**：实时显示音量波形与识别文字，另有极简悬浮窗模式（波形胶囊）。
- **正式主界面**：首页（输入统计与 Token 用量）、历史（可搜索、复制、删除）、设置三个标签；点击 Dock 图标可打开主窗口。
- **菜单栏**：显示听写 / 翻译快捷键，并提供专用菜单栏图标。
- **自定义应用图标**。
- 声音反馈为可选项，默认关闭。

## 稳定与安全

- **失败不丢字**：LLM 失败或超时可自动回退为 ASR 原文；ASR 断线时保留已识别内容供复制；`Esc` 随时取消，取消时不会插入任何文字。
- **三级插入**：Accessibility 直写 → 模拟粘贴（自动备份并恢复剪贴板）→ 悬浮窗手动复制。不会向密码框、安全输入模式或已切换的应用写入，也不会自动回车或提交。
- 插入过程中若焦点离开输入框，结果会复制到剪贴板并发出通知，避免内容丢失。
- **隐私优先**：API Key 只存 macOS Keychain；不保存音频；识别文字只存在本机历史中（可随时关闭或清空）；日志不含语音与文字内容。

## 系统要求

- macOS 26.0 及以上。
- 需要在系统设置的「隐私与安全性」中授予 **麦克风**、**辅助功能**、**输入监控** 权限。
- 需要自备阿里云百炼或 DeepSeek 的 API Key（ASR），以及你所选 LLM 服务的 API Key。

## 安装

下载 `OpenType-0.1.0.dmg`（或 `OpenType-0.1.0.zip`），将 `OpenType.app` 拖入「应用程序」文件夹。

本版本使用自签名证书签名，未经 Apple 公证，首次打开会被 Gatekeeper 拦截。请任选一种方式放行：

- 在「系统设置 → 隐私与安全性」中点击「仍要打开」；
- 或在终端执行：

```bash
xattr -dr com.apple.quarantine /Applications/OpenType.app
```

> 之后升级只要仍使用同一张证书签名，辅助功能 / 输入监控授权会保留。
