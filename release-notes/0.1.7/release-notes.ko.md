# OpenType 0.1.7 (8)

이번 릴리스에서는 어떤 앱에서든 텍스트를 다룰 수 있는 플로팅 패널 **글쓰기 도구**와, 음성 지시로 선택한 텍스트를 고쳐 주는 **음성 고쳐쓰기**를 추가했습니다.

> **시스템 요구 사항: macOS 26.0+ · Apple 실리콘(arm64)**

## 새로운 기능과 개선

- **글쓰기 도구(⌃⌥W)**: 선택한 텍스트(또는 캐럿) 옆에 플로팅 패널이 나타나 교정(변경 부분을 인라인 표시), 다시 쓰기, 어조 변경, 요약 / 핵심 요점 / 목록 / 표, 번역, 입력하거나 말로 할 수 있는 자유 명령 입력란을 제공합니다. 선택한 텍스트가 없으면 **작성**이 되며 생성(일반 텍스트, Markdown 표시 없음)과 **Markdown으로 생성**(제목, 목록, 굵게, 표 등) 두 버튼이 표시됩니다. 결과는 다듬기, 다시 생성, 복사가 가능하고 앱에 바꿔 넣거나 삽입할 수 있습니다(⌘Z로 실행 취소). 설정에 전용 단축키, 켜기/끄기, 프로필, 모델 ID, 추론 강도가 있고 패널 재질도 따로 고를 수 있습니다(기본값은 흐림 효과). 카드를 끌어 패널을 옮길 수 있으며 마우스 포인터 옆에서 열립니다.
- **스트리밍 응답**: 글쓰기 도구의 모든 응답이 모델이 작성하는 대로 문장 단위로 서서히 나타납니다. 「중지」 버튼으로 언제든 멈출 수 있고, 중단되거나 오류가 난 스트림은 선택한 텍스트를 바꾸지 않으며 결과가 완성되기 전에는 적용하거나 복사할 수 없습니다.
- **음성 고쳐쓰기**: 텍스트를 선택한 상태에서 받아쓰기를 시작하면 말한 내용이 수정 지시로 처리됩니다(예: “어조를 더 부드럽게”, “일본어로 번역”). 선택한 텍스트와 지시가 LLM에 전달되고 결과가 선택 영역을 대체합니다. 중간에 실패하면 선택한 텍스트는 그대로 유지됩니다. Chromium / Electron 앱(Claude, VS Code, Slack, Chrome 등)의 선택 영역도 올바르게 읽습니다.
- **번역할 때 현재 앱의 프리셋 적용**: 새 옵션(기본값 꺼짐)을 켜면 번역이 현재 앱의 프리셋(어조와 스타일, 전문 용어 사전 팩, 문장 끝 마침표 규칙)을 따릅니다. 「Terminal 명령 생성」 같은 명령 프리셋은 사용되지 않습니다. 적용될 때 오버레이에 프리셋 캡슐과 선택기가 표시됩니다.
- **프리셋**: 「반각 문장 부호」 옵션을 없애고, 문장 부호는 모델이 알아서 고릅니다(라틴 문자는 반각, 중국어는 전각).
- **수정**: 글쓰기 도구의 긴 결과가 자체 영역 안에서 스크롤되어 둥근 카드 밖으로 튀어나오지 않습니다. 카드 그림자를 더 부드럽게 하고, 형식 카드 크기를 같게 맞추고, 표 테두리를 정렬하고, 파란 포커스 링을 없앴으며, 글쓰기 도구에 전용 아이콘을 지정했습니다.

## 시스템 요구 사항

- **macOS 26.0 이상**.
- **Apple 실리콘(arm64) 전용**이며 Intel Mac은 지원하지 않습니다.
- 시스템 설정의 「개인정보 보호 및 보안」에서 **마이크**, **손쉬운 사용**, **입력 모니터링** 권한을 허용해야 합니다.
- Alibaba Cloud Bailian 또는 DeepSeek(음성 인식)의 API 키와, 선택한 LLM 서비스의 API 키를 직접 준비해야 합니다.

## 설치 및 업그레이드

0.1.3 이상을 사용 중이라면 앱 안에서 업데이트할 수 있습니다(설정 → 업데이트 확인). 그렇지 않다면 `OpenType-0.1.7-arm64.dmg`(또는 `OpenType-0.1.7-arm64.zip`)를 내려받아 `OpenType.app`을 「응용 프로그램」 폴더로 끌어다 놓아 이전 버전을 교체하세요.

이 빌드는 자체 서명 인증서로 서명되었고 Apple의 공증을 받지 않았으므로, 처음 실행할 때 Gatekeeper가 차단합니다. 다음 중 하나로 허용하세요.

- 시스템 설정 → 개인정보 보호 및 보안에서 「그래도 열기」를 클릭합니다.
- 또는 터미널에서 다음을 실행합니다.

```bash
xattr -dr com.apple.quarantine /Applications/OpenType.app
```

> 같은 인증서로 서명된 업그레이드라면 이미 허용한 손쉬운 사용 / 입력 모니터링 권한이 유지됩니다.
