# OpenType 0.1.7 (8)

このリリースでは、どのアプリでも文章を扱える浮動パネル **文章ツール** と、音声の指示で選択範囲を書き換える **音声で書き換え** を追加しました。

> **動作環境：macOS 26.0+ · Apple シリコン（arm64）**

## 新機能と改善

- **文章ツール（⌃⌥W）**：選択したテキスト（またはキャレット）の横に浮動パネルを表示し、校正（変更箇所をインライン表示）、書き換え、トーン変更、要約 / 要点 / リスト / 表、翻訳、入力でも音声でも使える自由入力の指示欄を使えます。何も選択していないときは **作成** になり、生成（プレーンテキスト、Markdown 記号なし）と **Markdown で生成**（見出し、リスト、太字、表など）の 2 つのボタンが表示されます。結果は調整、再生成、コピーができ、アプリへ置き換え・挿入もできます（⌘Z で取り消し）。設定には専用のショートカット、オン/オフ、プロファイル、モデル ID、推論強度があり、パネルの素材も個別に選べます（既定はすりガラス）。カードをドラッグしてパネルを動かせ、マウスポインタの横に開きます。
- **ストリーミング表示**：文章ツールのすべての返答が、モデルの生成に合わせて文ごとにフェードインしながら表示されます。「停止」ボタンでいつでも中止でき、中断・エラーになったストリームが選択範囲を置き換えることはなく、結果が完成するまで適用やコピーはできません。
- **音声で書き換え**：テキストを選択した状態で音声入力を始めると、話した内容が指示として扱われます（例：「もっと柔らかい口調に」「日本語に翻訳」）。選択範囲と指示が LLM に送られ、結果で選択範囲が置き換えられます。途中で失敗した場合、選択範囲はそのままです。Chromium / Electron アプリ（Claude、VS Code、Slack、Chrome など）の選択範囲も正しく取得できるようになりました。
- **翻訳時に現在のアプリのプリセットを適用**：新しいオプション（既定はオフ）をオンにすると、翻訳が現在のアプリのプリセット（口調とスタイル、辞書パック、文末の句点ルール）に従います。「Terminal コマンド生成」のようなコマンド系プリセットは使われません。適用時はオーバーレイにプリセットのカプセルと選択メニューが表示されます。
- **プリセット**：「半角句読点」オプションを廃止し、句読点はモデルが自分で選びます（ラテン文字は半角、中国語は全角）。
- **修正**：文章ツールの長い結果は専用の枠内でスクロールし、角丸カードからはみ出さなくなりました。カードの影をやわらげ、形式カードを同じ大きさにし、表の罫線をそろえ、青いフォーカスリングを廃止しました。文章ツールに専用アイコンを設定しました。

## 動作環境

- **macOS 26.0 以降**。
- **Apple シリコン（arm64）専用**です。Intel Mac には対応していません。
- システム設定の「プライバシーとセキュリティ」で、**マイク**、**アクセシビリティ**、**入力監視**の権限を許可してください。
- Alibaba Cloud Bailian または DeepSeek（音声認識）の API キーと、選択した LLM サービスの API キーをご自身で用意してください。

## インストールとアップデート

0.1.3 以降をお使いの場合は、アプリ内でアップデートできます（設定 → アップデートを確認）。それ以外の場合は `OpenType-0.1.7-arm64.dmg`（または `OpenType-0.1.7-arm64.zip`）をダウンロードし、`OpenType.app` を「アプリケーション」フォルダにドラッグして古いバージョンを置き換えてください。

このビルドは自己署名証明書で署名されており、Apple による公証は受けていないため、初回起動時に Gatekeeper にブロックされます。次のいずれかで許可してください。

- システム設定 → プライバシーとセキュリティで「このまま開く」をクリックする。
- または、ターミナルで次を実行する。

```bash
xattr -dr com.apple.quarantine /Applications/OpenType.app
```

> 同じ証明書で署名されたアップデートであれば、許可済みのアクセシビリティ / 入力監視の権限は保持されます。
